How to use

Each action calls the FastAPI REST API
  1. Create 1. Add a student Click Add Student and fill in the form. POST /students
  2. Read 2. View students Browse the table or click to see details. GET /students
  3. Update 3. Edit student information Click to change a student's details. PUT /students/{id}
  4. Delete 4. Delete students when needed Click and confirm. DELETE /students/{id}
